# Dinner Macro Matcher
> 專為早午餐固定、晚餐常有選擇障礙的外食族設計的營養素計算與晚餐推薦工具。

> 發想動機：因為我平常的早午餐組合非常固定，常常是特定幾樣超商食品在輪流吃。但是現在我正在減脂飲控中，因此非常在意涉入的熱量與營養成份。雖然晚餐也是以外食為主，但由於早午餐吃的組合略有不同，每天的活動量也不太相同，因此每天都很苦惱晚餐要吃甚麼，就以此為主題作為幫助我接下來評估晚餐選擇得小工具！

## 專案規格書 (Specification)

### 一、專案背景與核心痛點
現代上班族與學生通常早餐與午餐選擇相對固定（如超商、固定便當），但到了晚餐時段常面臨兩難：
1. 「不知道晚餐要吃什麼」的選擇障礙。
2. 缺乏對整日攝取熱量與三大營養素（碳水、蛋白質、脂肪）的總量概念，容易導致晚餐暴食碳水或蛋白質攝取嚴重不足。

本 Web App 旨在提供輕量、直覺的互動工具，讓使用者輸入個人生理數據計算代謝標準，填入早午餐攝取後，自動可視化「剩餘營養缺口」，並智慧推薦符合缺口的外食晚餐組合。

---

### 二、使用者流程 (User Flow)
1. **基本資料設定**：輸入性別、年齡、身高、體重、活動量與飲食目標（維持/溫和減脂/健康增肌），系統即時計算 BMR、TDEE 與當日各營養素目標克數。
2. **記錄早午餐**：透過常見外食快捷標籤一鍵累加填入，或手動微調實際攝取數值。
3. **儀表板即時分析**：四色進度條動態呈現「已攝取百分比」與「晚餐剩餘額度」；若單項超標則自動轉紅並給予飲食調整提示。
4. **晚餐外食推薦**：根據剩餘額度推薦適合的外食情境組合，並提供「換一個晚餐提案 🎲」抽籤互動功能。

---

### 三、功能規格與計算邏輯

#### 1. 代謝與營養素計算模組
* **BMR 公式（Mifflin-St Jeor）**：
  * 女性：$10 \times \text{體重(kg)} + 6.25 \times \text{身高(cm)} - 5 \times \text{年齡} - 161$
  * 男性：$10 \times \text{體重(kg)} + 6.25 \times \text{身高(cm)} - 5 \times \text{年齡} + 5$
* **TDEE 計算**：$\text{BMR} \times \text{活動係數}$（久坐 1.2 / 輕度運動 1.375 / 中度運動 1.55）
* **目標模式與熱量分配**：
  * **維持體重**：目標熱量 = TDEE（碳水 50%、蛋白質 20%、脂肪 30%）
  * **溫和減脂**：目標熱量 = TDEE - 300 kcal（碳水 40%、蛋白質 30%、脂肪 30%）
  * **健康增肌**：目標熱量 = TDEE + 300 kcal（碳水 45%、蛋白質 25%、脂肪 30%）
* **克數轉換基準**：碳水化合物 4 kcal/g、蛋白質 4 kcal/g、脂肪 9 kcal/g。

#### 2. 早午餐輸入模組
* **預設快捷選項（點擊自動累加）**：
  * 🥚 水煮蛋兩顆 (140 kcal / 碳水 1g / 蛋 14g / 脂 9g)
  * 🥛 無糖豆漿 (130 kcal / 碳水 5g / 蛋 14g / 脂 6g)
  * 🍠 超商地瓜 (180 kcal / 碳水 42g / 蛋 2g / 脂 0g)
  * 🍱 舒肥雞健康餐盒 (550 kcal / 碳水 60g / 蛋 40g / 脂 12g)
  * 🥪 蛋沙拉吐司 (320 kcal / 碳水 28g / 蛋 10g / 脂 18g)
  * 🥗 蔬菜沙拉 (90 kcal / 碳水 12g / 蛋 2g / 脂 3g)
* **自訂調整**：提供即時數值輸入框，可隨時手動微調與清空。

#### 3. 動態儀表板與警示模組
* **四色進度條**：
  * 總熱量：暖橘色
  * 碳水化合物：鵝黃色
  * 蛋白質：湖水綠
  * 脂肪：珊瑚粉
* **超標警示邏輯**：當單項攝取超過 100% 時，進度條顏色轉為警示紅，並提示具體飲食調整建議。

#### 4. 外食晚餐推薦引擎
* 內建超商、健康餐盒、台式小吃、清湯火鍋、鐵板料理等多種外食情境。
* 支援隨機輪播切換推薦。
